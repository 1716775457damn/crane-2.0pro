# 简化绝对位置控制系统使用指南

## 概述

本系统在严格保持现有通信协议和控制机制不变的基础上，新增了两个简化的绝对位置控制功能：

1. **简化底盘绝对位置控制** - 仅支持Y轴（前后）方向的绝对位置控制
2. **步进电机绝对位置控制** - 为4个步进电机提供绝对位置控制

## 技术约束和兼容性保证

### 严格保持的现有机制
- ✅ **底盘通信协议完全不变** - 继续使用19号引脚(CHASSIS_SERIAL_TX)的现有格式
- ✅ **步进电机控制机制不变** - 保持现有的使能/禁用控制和引脚配置
- ✅ **现有命令完全兼容** - 所有原有命令功能保持不变
- ✅ **静默通信模式** - 底盘控制仍为只发送不接收模式

### 新增功能作为扩展
- 新功能完全作为现有系统的扩展层
- 不修改任何现有的control_chassis_raw函数行为
- 不改变现有的controlStepper函数行为
- 位置跟踪系统独立运行，不影响原有控制

## 底盘简化绝对位置控制

### 功能特性
- **仅Y轴控制** - 只支持前后方向的绝对位置控制
- **位置跟踪** - 自动跟踪当前Y轴位置
- **协议保持** - 严格使用现有的control_chassis_raw函数

### 新增命令

#### 1. 绝对位置移动
```
chassis_abs,Y,S
```
- **Y**: 目标Y位置 (范围: -2000000 到 2000000)
- **S**: 移动速度 (可选，默认50)

**示例**:
```
chassis_abs,100000,50    # 移动到Y=100000，速度50
chassis_abs,0            # 返回Y=0，使用默认速度
chassis_abs,-50000,30    # 移动到Y=-50000，速度30
```

#### 2. 查看当前位置
```
chassis_pos
```
显示当前Y位置、校准状态和最后更新时间。

#### 3. 位置重置/校准
```
chassis_reset           # 重置到Y=0
chassis_reset,Y         # 重置到指定Y位置
```

**示例**:
```
chassis_reset           # 重置到Y=0
chassis_reset,100000    # 设置当前位置为Y=100000
```

### 坐标系统
- **Y轴正方向**: 前进方向
- **Y轴负方向**: 后退方向
- **位置单位**: 与现有chassis_adv命令相同
- **位置范围**: -2,000,000 到 2,000,000

## 步进电机绝对位置控制

### 功能特性
- **4电机支持** - 支持现有的4个步进电机(1-4)
- **位置跟踪** - 自动跟踪每个电机的绝对位置
- **自动使能** - 绝对位置命令会自动使能电机，无需手动使能
- **使能集成** - 完全集成现有的stepper_enable/disable机制

### 新增命令

#### 1. 绝对位置移动
```
stepper_abs,M,P,S,A
```
- **M**: 电机编号 (1-4)
- **P**: 目标绝对位置 (范围: -1000000 到 1000000)
- **S**: 最大速度 (1-200)
- **A**: 加速度 (可选，默认50)

**示例**:
```
stepper_abs,2,-1600,75,25    # 电机2移动到位置-1600，速度75，加速度25 (自动使能)
stepper_abs,1,1000,100,50    # 电机1移动到位置1000，速度100，加速度50 (自动使能)
stepper_abs,3,-200,120       # 电机3移动到位置-200，速度120 (自动使能)
```

#### 2. 查看位置
```
stepper_pos,M           # 查看指定电机位置
stepper_pos,all         # 查看所有电机位置
```

**示例**:
```
stepper_pos,1           # 查看电机1位置
stepper_pos,all         # 查看所有电机位置
```

#### 3. 位置重置/校准
```
stepper_reset,M,P       # 重置电机M到位置P
stepper_reset,M         # 重置电机M到位置0
```

**示例**:
```
stepper_reset,1,0       # 重置电机1到位置0
stepper_reset,2,500     # 重置电机2到位置500
stepper_reset,3         # 重置电机3到位置0
```

## 与现有系统的兼容性

### 现有命令增强
原有命令现在会自动更新位置跟踪：

```
# 底盘相对移动 - 现在会自动更新Y位置跟踪
chassis_adv,1,50000,50      # 前进50000单位，位置自动更新

# 步进电机相对移动 - 现在会自动更新位置跟踪  
stepper,1,200,100           # 电机1移动200步，位置自动更新
```

### 混合使用示例
```
# 1. 重置所有位置
chassis_reset
stepper_reset,1
stepper_reset,2

# 2. 使用绝对位置移动
chassis_abs,100000,50
stepper_abs,1,500,100

# 3. 使用相对移动（位置会自动更新）
chassis_adv,1,20000,50      # Y位置从100000变为120000
stepper,1,100,80            # 电机1位置从500变为600

# 4. 查看更新后的位置
chassis_pos
stepper_pos,1
```

## 注意事项

### 1. 位置精度
- 位置跟踪基于命令执行，实际位置可能有累积误差
- 建议定期使用reset命令重新校准位置
- 位置容差：底盘1000单位，步进电机1步

### 2. 使能控制
- 步进电机必须先使能才能进行绝对位置移动
- 使能状态与现有系统完全同步
- 禁用电机时绝对位置移动会被拒绝

### 3. 通信协议
- 底盘控制严格保持现有的19号引脚TX-only模式
- 不会从其他串口向底盘发送任何数据
- 完全使用现有的control_chassis_raw函数

### 4. 范围限制
- 底盘Y位置：±2,000,000
- 步进电机位置：±1,000,000
- 步进电机速度：1-200
- 超出范围的命令会被拒绝

## 故障排除

### 常见问题

1. **位置不准确**
   - 使用相应的reset命令重新校准
   - 检查移动命令是否正确执行

2. **步进电机不响应**
   - 检查电机是否已使能：`stepper_enable,N`
   - 验证电机编号是否正确(1-4)

3. **底盘移动异常**
   - 验证现有chassis_adv命令是否正常工作
   - 检查19号引脚连接

4. **位置跟踪失效**
   - 重启系统重新初始化
   - 使用reset命令重新校准
