# ESP32S3模块测试程序

## 概述

ESP32S3模块测试程序是一个用于测试各种硬件模块的综合性工具，支持灰度传感器、舵机、激光测距传感器和底盘控制等功能。程序通过串口命令进行控制，同时支持本地串口和主机通信。

**最新更新**:
- **移除浮点运算**: 激光传感器代码中的所有浮点运算已被整型运算替代，提高了在资源有限的处理器上的执行效率
- **安全性提升**: 增加了测试模式检查，只有在对应的测试模式下才能控制设备（舵机、底盘等）
- **优化算法**: 滤波器和稳定性检测算法已经使用整型计算重新实现

## 硬件要求

- ESP32S3开发板
- 灰度传感器(5通道)
- 舵机(最多3个)
- 激光测距传感器
- 底盘控制模块

## 引脚配置

### 通信引脚
- 主机通信串口: TX(20), RX(21), 波特率115200
- 底盘控制串口: TX(19), 波特率115200

### 传感器引脚
- 灰度传感器: 
  - R2(10) - 最右侧传感器
  - R1(11) - 右侧传感器
  - M(12) - 中间传感器
  - L1(13) - 左侧传感器
  - L2(14) - 最左侧传感器

- 激光传感器: 
  - 激光1: RX(36), TX(35)，使用Serial2
  - 激光2: RX(46), TX(9)，使用Serial1

### 控制引脚
- 舵机引脚:
  - 舵机1: 引脚18
  - 舵机2: 引脚8
  - 舵机3: 引脚3

- 步进电机引脚:
  - 电机1: SLEEP(4), DIR(5), STEP(6)
  - 电机2: SLEEP(7), DIR(15), STEP(16)
  - 电机3: SLEEP(42), DIR(41), STEP(40)
  - 电机4: SLEEP(39), DIR(38), STEP(37)

- RGB LED引脚: 48

## 串口命令

程序支持以下命令(带括号和不带括号均可):

### 基本命令
- `color` 或 `(color)` - 进入灰度传感器测试模式，输出原始数值
- `laser1` 或 `(laser1)` - 获取激光传感器1原始数据
- `laser2` 或 `(laser2)` - 获取激光传感器2原始数据
- `help` 或 `(help)` - 显示帮助信息
- `exit` 或 `(exit)` - 退出当前模式

### 舵机控制
- `servo,N,A` 或 `(servo,N,A)` - 舵机测试，将#N舵机调整到A度
  - 例如: `servo,1,90` - 将1号舵机调整到90度
  - **注意**: 只有在舵机测试模式下才能控制舵机
- `servosweep` 或 `(servosweep)` - 进入舵机扫描测试模式，依次控制所有舵机从0度到180度往复运动

### 底盘控制
- `chassis,D,S` 或 `(chassis,D,S)` - 控制底盘，D=方向(0-4)，S=速度(0-100)
  - 方向: 0-停止, 1-前进, 2-后退, 3-左转, 4-右转
  - **注意**: 只有在底盘测试模式下才能控制底盘

### 引脚测试
- `pintest` 或 `(pintest)` - 进入数字引脚测试模式，自动测试所有可用引脚
- `pin,N,S` 或 `(pin,N,S)` - 设置引脚N的状态S(0/1)
  - 例如: `pin,13,1` - 将13号引脚设置为高电平

### 模拟输入测试
- `adctest` 或 `(adctest)` - 进入模拟输入测试模式，读取所有ADC通道
- `adc,N` 或 `(adc,N)` - 读取引脚N的模拟值
  - 例如: `adc,1` - 读取1号引脚的模拟值

### 激光传感器测试
进入激光传感器测试模式后，支持以下子命令：

- `detail` 或 `(detail)` - 显示详细调试信息模式，包括原始值、滤波后值、变化率和稳定性
- `basic` 或 `(basic)` - 显示基本调试信息模式（默认模式）
- `raw` 或 `(raw)` - 仅显示原始数据模式
- `continuous` 或 `(continuous)` - 开启连续采样模式
- `once` 或 `(once)` - 开启单次采样模式（默认模式）
- `reset` 或 `(reset)` - 重置传感器
- `mode,N` 或 `(mode,N)` - 设置输出模式，其中N为：
  - 0 = 最远目标优先
  - 1 = 最强信号优先
  - 2 = 多目标模式
- `help` 或 `(help)` - 显示激光传感器命令帮助

## 测试模式说明

### 灰度传感器测试
在此模式下，程序会持续读取5个灰度传感器的值并输出。可用于调整传感器位置和检测黑线。
- 输出格式: `GRAY:value1,value2,value3,value4,value5`
- 数值范围: 0-4095，值越大表示检测到的颜色越深

### 激光传感器测试
在此模式下，程序会持续读取激光传感器的距离值并输出。可用于检测障碍物距离。

**特别说明**: 所有激光传感器代码现在使用整型运算，不再使用浮点运算，提高了效率和兼容性。滤波和稳定性检测算法已重新使用整型实现。

支持多种调试模式：
- **基本模式**：显示距离值和滤波后的距离值
- **详细模式**：显示原始距离、滤波后距离、变化率和稳定性信息
- **原始数据模式**：只显示未经处理的原始距离数据

支持两种采样模式：
- **连续采样**：自动持续读取并显示传感器数据
- **单次采样**：每秒读取一次传感器数据

输出格式: 
- 激光传感器1: `LASER1:distance`
- 激光传感器2: `LASER2:distance`
- 详细模式: `LASER1:distance,FILTER:filtered,STABLE:stability`

数值单位: 毫米(mm)

### 舵机测试
可以通过命令控制三个舵机的角度，或使用自动扫描模式测试舵机的工作范围。
- 角度范围: 0-180度
- 扫描步长: 5度
- **安全限制**: 舵机只能在舵机扫描测试模式和引脚测试模式下控制

### 底盘控制测试
可以控制底盘的运动方向和速度，用于测试底盘电机和控制系统。
- 方向: 停止、前进、后退、左转、右转
- 速度范围: 0-100%
- **安全限制**: 底盘只能在底盘测试模式下控制

### 引脚测试
可以测试ESP32S3的数字输出功能，设置各引脚的高低电平状态。
- 自动测试模式会依次切换所有可用引脚的状态
- 手动模式可以精确控制单个引脚

### 模拟输入测试
可以读取ESP32S3的模拟输入通道，测试传感器或电位器等模拟设备。
- ADC范围: 0-4095 (12位)
- 支持通道: 1-10

## 使用方法

1. 将硬件模块连接到ESP32S3，按照引脚配置正确连接
2. 将程序烧录到ESP32S3
3. 打开串口监视器(波特率115200)
4. 输入`help`查看可用命令
5. 根据需要选择相应的测试模式

## 数据格式

在传感器测试模式下，数据会通过本地串口和主机通信端口自动发送。主机通信格式为:

- 灰度传感器: `GRAY:value1,value2,value3,value4,value5`
- 激光传感器1: `LASER1:distance`
- 激光传感器2: `LASER2:distance`
- 激光传感器(详细模式): `LASER1:distance,FILTER:filtered,STABLE:stability`
- 状态消息: `STATUS:message`

## 调试信息

程序会在启动时显示详细的初始化过程，并每5秒输出一次心跳消息。命令处理过程中会显示接收到的原始命令和处理后的命令，便于调试。

## 故障排除

如果遇到问题，请检查:

1. 串口连接是否正确(波特率115200)
2. 硬件连接是否符合引脚定义
3. 观察串口输出的调试信息
4. 命令格式是否正确

如果串口没有输出，可能需要按下ESP32S3的复位按钮重新启动程序。

### 常见问题

1. **串口只显示"HOST_SERIAL_TEST"**
   - 检查程序是否在初始化过程中崩溃
   - 尝试断开并重新连接硬件
   - 按下复位按钮重启ESP32S3

2. **命令无响应**
   - 确保命令格式正确，可以带括号或不带括号
   - 检查命令是否包含正确的参数
   - 观察串口输出的命令解析信息

3. **传感器数据异常**
   - 检查传感器连接是否正确
   - 确认传感器供电是否稳定
   - 检查引脚定义是否与实际连接一致

4. **舵机不动作**
   - 检查是否在正确的测试模式下（舵机扫描测试或引脚测试模式）
   - 检查舵机供电是否充足
   - 确认舵机信号线连接正确
   - 尝试使用较小的角度变化测试舵机

5. **底盘不动作**
   - 确认是否在底盘测试模式下发送命令
   - 检查底盘控制命令的格式是否正确
   - 检查底盘电源是否接通

6. **激光传感器读取失败**
   - 检查串口连接是否正确（TX->RX, RX->TX）
   - 使用`reset`命令重置传感器
   - 尝试不同的输出模式（`mode,0`、`mode,1`或`mode,2`）
   - 检查传感器电源是否稳定
   - 如果持续失败，尝试断开电源并重新连接传感器

## 注意事项

- 程序启动后会自动显示帮助信息
- 所有串口输出均为中文，方便国内用户使用
- 命令不区分大小写，可以带括号或不带括号
- 在测试模式下，数据会持续输出，直到输入`exit`命令退出
- 测试引脚时注意避开已用于特殊功能的引脚(如串口通信引脚)
- 使用底盘控制功能时，确保周围有足够的空间，并且在进入底盘测试模式后才能控制
- 激光传感器有多种调试模式，可根据需求选择合适的模式
- 传感器代码优化为整型计算，不再使用浮点运算，适合在资源受限的环境下运行
