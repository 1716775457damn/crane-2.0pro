# 舵机360度控制测试说明

## 修改内容

已成功修改舵机控制代码，使所有舵机支持0到360度的角度控制。

### 主要修改

1. **servo1()函数** - 支持0-360度角度控制
2. **servo2()函数** - 支持0-360度角度控制  
3. **servo3()函数** - 支持0-360度角度控制
4. **servoAll()函数** - 支持同时控制三个舵机到0-360度
5. **initServos()函数** - 初始化时支持0-360度角度设置

### 脉冲宽度计算

- **原来**: `pulsewidth = (angle * 11) + 500` (0-180度，500-2480微秒)
- **现在**: `pulsewidth = (angle * 2000 / 360) + 500` (0-360度，500-2500微秒)

### 串口命令使用

现在可以使用以下命令控制舵机到0-360度的任意角度：

```
servo,1,0      # 舵机1转到0度
servo,1,90     # 舵机1转到90度
servo,1,180    # 舵机1转到180度
servo,1,270    # 舵机1转到270度
servo,1,360    # 舵机1转到360度

servo,2,45     # 舵机2转到45度
servo,2,135    # 舵机2转到135度
servo,2,225    # 舵机2转到225度
servo,2,315    # 舵机2转到315度

servo,3,120    # 舵机3转到120度
servo,3,240    # 舵机3转到240度
```

### 测试步骤

1. 上传修改后的代码到ESP32-S3
2. 打开串口监视器（波特率115200）
3. 输入 `help` 查看命令列表
4. 使用 `servo,N,A` 命令测试舵机，其中：
   - N = 舵机编号 (1, 2, 3)
   - A = 角度值 (0-360)

### 示例测试序列

```
servo,1,0      # 舵机1到0度
servo,1,90     # 舵机1到90度
servo,1,180    # 舵机1到180度
servo,1,270    # 舵机1到270度
servo,1,360    # 舵机1到360度（等同于0度）

servo,2,45     # 舵机2到45度
servo,2,135    # 舵机2到135度
servo,2,225    # 舵机2到225度
servo,2,315    # 舵机2到315度

servo,3,60     # 舵机3到60度
servo,3,120    # 舵机3到120度
servo,3,180    # 舵机3到180度
servo,3,240    # 舵机3到240度
servo,3,300    # 舵机3到300度
```

### 注意事项

1. **舵机类型**: 确保使用的是360度连续旋转舵机，而不是标准的180度舵机
2. **角度范围**: 代码会自动限制角度在0-360度范围内
3. **脉冲宽度**: 新的脉冲宽度计算适用于大多数360度舵机
4. **调试信息**: 每次舵机移动都会输出调试信息到串口

### 硬件连接

- 舵机1: GPIO 18 (SERVO_PIN_1)
- 舵机2: GPIO 8  (SERVO_PIN_2)  
- 舵机3: GPIO 3  (SERVO_PIN_3)

### 故障排除

如果舵机不能正确响应360度控制：

1. 检查舵机是否为360度连续旋转型
2. 验证硬件连接是否正确
3. 调整脉冲宽度范围（如需要可修改代码中的500-2500微秒范围）
4. 检查电源供应是否充足

## 代码修改总结

所有舵机控制函数已成功升级为支持0-360度角度控制，串口命令帮助信息也已更新。现在可以通过串口调试实现对所有舵机的全角度控制。
