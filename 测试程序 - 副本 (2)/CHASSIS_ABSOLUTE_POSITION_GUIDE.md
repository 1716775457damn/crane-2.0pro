# 底盘绝对位置控制系统使用指南

## 概述

本系统在原有的相对位置控制基础上，新增了绝对位置控制功能，允许您通过串口命令让底盘移动到指定的绝对坐标位置。

## 功能特性

### 1. 位置跟踪系统
- **坐标系统**: 使用X-Y坐标系，原点(0,0)为初始位置
- **位置记录**: 实时跟踪当前位置和朝向
- **位置更新**: 每次移动后自动更新位置信息
- **校准状态**: 跟踪系统是否已校准

### 2. 绝对位置移动
- **分步移动**: 先X方向移动，再Y方向移动
- **智能路径**: 自动计算最优移动路径
- **容差控制**: 支持位置容差设置
- **范围检查**: 自动检查目标坐标是否在有效范围内

### 3. 位置管理
- **位置查询**: 随时查看当前位置
- **位置重置**: 手动校准当前位置
- **状态监控**: 显示位置更新时间和校准状态

## 新增串口命令

### 1. 绝对位置移动
```
chassis_abs,X,Y,S
```
- **X**: 目标X坐标 (范围: -1000000 到 1000000)
- **Y**: 目标Y坐标 (范围: -1000000 到 1000000)  
- **S**: 移动速度 (可选，默认50)

**示例**:
```
chassis_abs,100000,200000,50    # 移动到(100000,200000)，速度50
chassis_abs,0,0                 # 返回原点，使用默认速度
chassis_abs,-50000,100000,30    # 移动到(-50000,100000)，速度30
```

### 2. 查看当前位置
```
chassis_pos
```
显示当前位置信息，包括：
- X、Y坐标
- 朝向角度
- 校准状态
- 最后更新时间

### 3. 位置重置/校准
```
chassis_reset                   # 重置到原点(0,0,0°)
chassis_reset,X,Y,H            # 重置到指定位置和朝向
```
- **X**: 新的X坐标
- **Y**: 新的Y坐标
- **H**: 新的朝向角度 (度，可选，默认0)

**示例**:
```
chassis_reset                   # 重置到原点
chassis_reset,100000,200000     # 设置当前位置为(100000,200000)
chassis_reset,0,0,90           # 重置到原点，朝向90度
```

## 坐标系统说明

### 坐标单位
- 坐标单位与您现有的`chassis_adv`命令中的距离单位相同
- 根据您的示例`chassis_adv,2,100000,1`，单位可能是微米或编码器单位

### 方向定义
- **X轴**: 正方向为右，负方向为左
- **Y轴**: 正方向为前，负方向为后
- **朝向**: 0度为正Y方向（前），90度为正X方向（右）

### 坐标范围
- X坐标: -1,000,000 到 1,000,000
- Y坐标: -1,000,000 到 1,000,000
- 位置容差: 1,000 单位

## 与现有系统的兼容性

### 相对移动命令增强
原有的`chassis_adv`命令现在会自动更新位置跟踪：
```
chassis_adv,2,100000,1          # 相对移动，位置会自动更新
chassis_pos                     # 查看更新后的位置
```

### 混合使用
可以混合使用相对移动和绝对移动：
```
chassis_abs,100000,100000       # 绝对移动到(100000,100000)
chassis_adv,1,50000,50          # 相对前进50000单位
chassis_pos                     # 位置应为(100000,150000)
chassis_abs,0,0                 # 绝对移动回原点
```

## 注意事项

### 1. 位置精度
- 位置跟踪基于命令执行，实际位置可能有累积误差
- 建议定期使用`chassis_reset`重新校准位置
- 位置容差设置为1000单位，可根据需要调整

### 2. 移动策略
- 当前实现采用分步移动（先X后Y）
- 对于需要直线移动的应用，可能需要进一步优化算法

### 3. 坐标范围
- 坐标范围限制在±1,000,000，超出范围的命令会被拒绝
- 可根据实际应用需求调整范围限制

### 4. 速度控制
- 速度参数与原有系统保持一致
- 建议在测试时使用较低速度以确保精度

## 故障排除

### 常见问题

1. **位置不准确**
   - 使用`chassis_reset`重新校准
   - 检查移动命令是否正确执行

2. **坐标超出范围**
   - 检查目标坐标是否在±1,000,000范围内
   - 调整目标坐标或修改代码中的范围限制

3. **移动不到位**
   - 检查底盘硬件连接
   - 验证原有`chassis_adv`命令是否正常工作

4. **位置跟踪失效**
   - 重启系统重新初始化
   - 使用`chassis_reset`重新校准

- `updatePosition()`: 更新位置跟踪
