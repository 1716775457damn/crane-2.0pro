# ESP32-S3 机器人中文串口指令表

## 📋 基本命令

| 指令 | 功能说明 | 示例 |
|------|----------|------|
| `help` | 显示帮助信息 | `help` |
| `debug` | 显示调试信息 | `debug` |
| `status` | 显示详细系统状态 | `status` |
| `restart` | 重启系统 | `restart` |
| `test_serial` | 测试串口连接状态 | `test_serial` |
| `test_laser` | 测试激光传感器（5次读取） | `test_laser` |
| `test_chassis` | 测试底盘通信 | `test_chassis` |

## 🎯 位置管理命令

| 指令 | 功能说明 | 示例 |
|------|----------|------|
| `positions` | 显示所有设备当前位置 | `positions` |
| `reset_positions` | 重置所有位置为原点 | `reset_positions` |

## 🚗 底盘绝对位置控制

| 指令格式 | 功能说明 | 参数说明 | 示例 |
|----------|----------|----------|------|
| `chassis_to_x,X[,S]` | 移动底盘到X位置 | X: 目标X坐标(mm), S: 速度(1-100) | `chassis_to_x,200,80` |
| `chassis_to_y,Y[,S]` | 移动底盘到Y位置 | Y: 目标Y坐标(mm), S: 速度(1-100) | `chassis_to_y,-100,60` |
| `chassis_to_angle,A` | 旋转底盘到指定角度 | A: 目标角度(度) | `chassis_to_angle,90` |
| `chassis_to_pos,X,Y` | 移动底盘到指定位置 | X,Y: 目标坐标(mm) | `chassis_to_pos,200,150` |
| `chassis_move,DIR,S` | 直接控制底盘移动 | DIR: 方向(f/b/l/r/s), S: 速度(1-100) | `chassis_move,f,80` |

### 底盘直接控制方向说明
- **f/forward**: 前进
- **b/backward**: 后退
- **l/left**: 左转
- **r/right**: 右转
- **s/stop**: 停止

### 底盘坐标系说明
- **X轴**: 前后方向，正值=前进，负值=后退
- **Y轴**: 左右方向，正值=右移，负值=左移  
- **角度**: 0-360度，正值=顺时针旋转

## ⚙️ 步进电机绝对位置控制

| 指令格式 | 功能说明 | 参数说明 | 示例 |
|----------|----------|----------|------|
| `stepper_to,M,P[,S]` | 移动电机到绝对位置 | M: 电机号(1-4), P: 目标位置(步数), S: 速度(1-255) | `stepper_to,1,200,100` |
| `stepper_rel,M,ST[,S]` | 电机相对移动 | M: 电机号(1-4), ST: 相对步数, S: 速度(1-255) | `stepper_rel,1,100,80` |
| `stepper_pos,M` | 显示电机位置 | M: 电机号(1-4) | `stepper_pos,1` |
| `stepper_positions` | 显示所有电机位置 | 无参数 | `stepper_positions` |

## ⚡ 性能控制命令

| 指令 | 功能说明 | 示例 |
|------|----------|------|
| `fast_mode` | 启用快速响应模式（200微秒脉冲间隔） | `fast_mode` |
| `normal_mode` | 启用正常响应模式（500微秒脉冲间隔） | `normal_mode` |

### 性能模式说明
- **快速模式**: 最高响应速度，适合精确控制和调试
- **正常模式**: 平衡性能和稳定性，适合长期运行
- **建议**: 根据实际需求选择合适的模式

### 步进电机说明
- **电机编号**: 1-4 (对应4个步进电机)
- **位置单位**: 步数 (steps)
- **方向**: 正值=顺时针，负值=逆时针
- **位置范围**: -2147483648 ~ 2147483647 步

## 📡 网络和串口信息

### WiFi热点信息
- **热点名称**: `ServoController`
- **密码**: `12345678`
- **IP地址**: `192.168.4.1`
- **Web界面**: `http://192.168.4.1`

### 串口配置
- **USB串口**: 115200波特率 (主要调试接口)
- **Serial1**: 9600波特率, TX=19 (底盘控制)
- **Serial2**: 115200波特率, RX=21, TX=20 (上位机通信)
- **Serial0**: 115200波特率, RX=36, TX=35 (激光传感器)

## 💡 使用示例

### 基本操作流程
```
1. help                    # 查看所有命令
2. status                  # 检查系统状态
3. positions              # 查看当前位置
4. reset_positions        # 重置所有位置为原点
```

### 底盘移动示例
```
# 绝对位置控制（支持速度设置）
chassis_to_x,200,80       # 以80速度前进到X=200mm
chassis_to_y,100,60       # 以60速度右移到Y=100mm
chassis_to_angle,90       # 右转90度
chassis_to_pos,0,0        # 回到原点

# 直接移动控制
chassis_move,f,80         # 以80速度前进
chassis_move,b,60         # 以60速度后退
chassis_move,l,50         # 以50速度左转
chassis_move,r,70         # 以70速度右转
chassis_move,s,0          # 停止
```

### 步进电机控制示例
```
# 绝对位置控制（支持速度设置）
stepper_to,1,200,100      # 电机1以100速度移动到200步位置
stepper_to,2,-100,80      # 电机2以80速度移动到-100步位置
stepper_rel,1,50,120      # 电机1以120速度在当前位置基础上前进50步
stepper_positions         # 查看所有电机位置
stepper_pos,1             # 查看电机1位置
```

### 传感器监控示例
```
gray                      # 开启灰度传感器连续输出
laser                     # 开启激光传感器连续输出
test_laser               # 测试激光传感器
```

### 性能优化示例
```
fast_mode                # 启用快速响应模式
stepper_to,1,200         # 快速移动电机1到200步
chassis_to_x,100         # 快速移动底盘到100mm
normal_mode              # 恢复正常模式
```

## ⚠️ 注意事项

1. **位置记录**: 系统会自动跟踪所有设备位置，断电后需要重新校准
2. **安全移动**: 移动前请确保路径安全，避免碰撞
3. **参数范围**: 请确保输入参数在有效范围内
4. **命令格式**: 严格按照格式输入，注意逗号分隔
5. **坐标系**: 请熟悉底盘坐标系定义，避免移动方向错误

## 🔍 故障排除

### 常见问题
1. **命令无响应**: 检查串口连接和波特率设置
2. **位置不准确**: 执行 `reset_positions` 重新校准
3. **移动失败**: 检查硬件连接和电源供应
4. **网页控制失效**: 确保WiFi连接正常，访问 `http://192.168.4.1`

### 调试命令
```
test_serial              # 测试串口连接
status                   # 查看系统状态
debug                    # 显示调试信息
```
