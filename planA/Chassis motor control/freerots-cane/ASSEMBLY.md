# ESP32智能拐杖 - 硬件组装指南

本文档提供ESP32智能拐杖项目的硬件组装步骤和调试指南，帮助您正确组装和测试系统。

## 所需材料清单

- ESP32开发板 x1
- D36A步进电机驱动模块 x2
- 步进电机 x2
- SG90舵机 x1
- HC-SR04超声波传感器 x1
- 循迹传感器模组（5个光电传感器） x1
- 机械结构件（拐杖架构、电机支架等）
- 电源模块（电池或稳压电源）
- 面包板和跳线
- 电阻：1KΩ x2, 2KΩ x1, 10KΩ x1
- 螺丝、螺母和支架
- 热缩管或绝缘胶带

## 组装步骤

### 1. 准备工作

1. 准备好所有组件和工具
2. 确认电池充电状态良好
3. 查看各个组件的数据手册，确认工作电压和接口

### 2. ESP32开发板准备

1. 使用USB数据线连接ESP32到电脑
2. 安装必要的驱动程序
3. 使用PlatformIO或Arduino IDE上传代码

### 3. 步进电机驱动模块组装

1. 将D36A步进电机驱动模块固定在机械结构上
2. 根据WIRING.md文件中的接线说明连接步进电机驱动模块与ESP32
3. 连接步进电机到驱动模块：
   - 电机1的A+/A-连接到驱动模块1的相应端子
   - 电机1的B+/B-连接到驱动模块1的相应端子
   - 电机2的A+/A-连接到驱动模块2的相应端子
   - 电机2的B+/B-连接到驱动模块2的相应端子
4. 使用热缩管或绝缘胶带保护接线连接点

### 4. 舵机安装

1. 将舵机固定在拐杖的抓取机构上
2. 连接舵机的信号线到ESP32的GPIO23
3. 连接舵机的电源线到5V电源
4. 连接舵机的地线到系统地线

### 5. 超声波传感器安装

1. 将超声波传感器固定在拐杖前端
2. 构建ECHO引脚分压电路：
   ```
   ECHO引脚 ---- 1KΩ电阻 ---- ESP32 GPIO33
                  |
               2KΩ电阻
                  |
                 GND
   ```
3. 连接TRIG引脚到ESP32的GPIO25
4. 连接VCC到5V电源
5. 连接GND到系统地线

### 6. 循迹传感器模组安装

1. 将循迹传感器模组固定在拐杖底部，保证所有传感器朝向地面
2. 连接传感器信号线到ESP32的指定引脚：
   - 传感器1 -> GPIO13
   - 传感器2 -> GPIO12
   - 传感器3 -> GPIO14
   - 传感器4 -> GPIO27
   - 传感器5 -> GPIO26
3. 连接VCC到3.3V或5V（根据传感器规格）
4. 连接GND到系统地线

### 7. 电源电压检测电路组装

1. 构建分压电路：
   ```
   电池正极 ---- 10KΩ电阻 ---- ESP32 GPIO7(ADC)
                  |
                1KΩ电阻
                  |
                 GND
   ```
2. 使用热缩管保护电阻连接点

### 8. 机械结构组装

1. 按照机械设计图组装拐杖框架
2. 固定电机和舵机到相应位置
3. 安装控制电路板和电源模块
4. 使用线扎或绝缘胶带固定各个连接线，防止松动

### 9. 电源连接

1. 连接电池到系统
2. 为步进电机驱动提供独立的电源（12V-24V）
3. 确保所有模块共地

## 调试和测试

### 1. 初始化测试

1. 上电前检查所有连接，确保无短路
2. 使用万用表测量关键点的电压
3. 接通电源，观察系统是否正常启动

### 2. 舵机测试

1. 运行以下代码测试舵机功能：
   ```c
   void testServo() {
     servo1(65);  // 测试抓取位置
     delay(1000);
     servo1(105);  // 测试释放位置
     delay(1000);
   }
   ```

### 3. 步进电机测试

1. 运行以下代码分别测试两个步进电机：
   ```c
   void testSteppers() {
     // 测试步进电机1
     controlStepper(stepper1, 1000, 1000, 1000);  // 上升
     delay(1000);
     controlStepper(stepper1, 1000, 1000, 0);  // 回到初始位置
     
     // 测试步进电机2
     controlStepper(stepper2, 1000, 1000, 1000);  // 右移
     delay(1000);
     controlStepper(stepper2, 1000, 1000, 0);  // 回到初始位置
   }
   ```

### 4. 超声波传感器测试

1. 在串口监视器上打印距离值：
   ```c
   void testUltrasonic() {
     float distance = measureDistanceAndSetState();
     Serial.print("Distance: ");
     Serial.println(distance);
     delay(500);
   }
   ```
2. 将物体放在传感器前方不同距离，确认测量值的准确性

### 5. 循迹传感器测试

1. 打印各个传感器的原始值和转换后的二进制状态：
   ```c
   void testTracingSensors() {
     Serial.print("Sensor 1: ");
     Serial.print(analogRead(13));
     Serial.print(" Sensor 2: ");
     Serial.print(analogRead(12));
     // ... 其他传感器
     
     int control = combinedSensorControl();
     Serial.print(" Control: ");
     Serial.println(control);
     delay(500);
   }
   ```
2. 使用黑色胶带在白色表面上创建不同的路径模式，测试传感器反应

### 6. 系统集成测试

1. 运行完整程序，测试各个功能的配合
2. 使用串口监视器观察系统状态变化
3. 测试不同场景下的系统响应：
   - 障碍物检测和避障
   - 循迹导航
   - 物体抓取和放置

## 调整和优化

### 1. 传感器阈值调整

1. 根据实际环境光线调整循迹传感器阈值：
   ```c
   uint16_t thresholdR1 = 800;  // 调整这个值
   uint16_t thresholdR2 = 800;  // 调整这个值
   // ... 其他阈值
   ```

2. 调整超声波传感器触发距离：
   ```c
   if (averageDistance <= 9)  // 调整这个值
   {
       chaosheng = 0;
   }
   ```

### 2. 电机速度和加速度调整

1. 根据负载情况调整步进电机参数：
   ```c
   controlStepper(stepper1, 950, 1800, 3700);  // 调整速度和加速度
   ```

### 3. 延时参数调整

1. 根据系统反应速度调整各个延时：
   ```c
   delay(500);  // 调整这个值
   ```

### 4. 舵机角度调整

1. 根据机械结构调整舵机的抓取和释放角度：
   ```c
   servo1(65);  // 抓取角度，调整这个值
   servo1(105);  // 释放角度，调整这个值
   ```

## 常见问题解决

### 1. 步进电机不转动

- 检查电源连接和电压
- 检查驱动模块和ESP32的连接
- 确认SLEEP引脚设置为HIGH
- 检查电机线圈连接是否正确

### 2. 舵机抖动或位置不准确

- 检查电源电压是否稳定
- 调整舵机角度参数
- 确认舵机信号线连接正确
- 考虑为舵机提供独立的电源

### 3. 超声波传感器测量不准确

- 检查分压电路连接
- 远离强电磁干扰源
- 增加测量次数取平均值
- 清洁传感器表面

### 4. 循迹传感器误判

- 调整传感器高度，距离地面约5-10mm
- 调整阈值参数
- 改善环境光线条件
- 使用对比度更高的路径标记
