本文档提供了ESP32智能拐杖项目的详细接线说明，包括各个模块的引脚连接和接线注意事项。

## 模块接线详解

### 1. 步进电机驱动模块（D36A）

使用的是D36A步进电机驱动模块，每个电机需要连接以下引脚：

#### 步进电机1连接：
- **VCC**: 连接到电源正极（根据电机规格，通常为12-24V）
- **GND**: 连接到电源负极
- **PUL+/STEP+**: 连接到5V
- **PUL-/STEP-**: 通过限流电阻连接到ESP32的GPIO18
- **DIR+**: 连接到5V
- **DIR-**: 通过限流电阻连接到ESP32的GPIO8
- **ENA+**: 连接到5V
- **ENA-**: 通过限流电阻连接到ESP32的GPIO3
- **A+, A-**: 连接到步进电机的A相线圈
- **B+, B-**: 连接到步进电机的B相线圈

#### 步进电机2连接：
- **VCC**: 连接到电源正极（根据电机规格，通常为12-24V）
- **GND**: 连接到电源负极
- **PUL+/STEP+**: 连接到5V
- **PUL-/STEP-**: 通过限流电阻连接到ESP32的GPIO15
- **DIR+**: 连接到5V
- **DIR-**: 通过限流电阻连接到ESP32的GPIO16
- **ENA+**: 连接到5V
- **ENA-**: 通过限流电阻连接到ESP32的GPIO17
- **A+, A-**: 连接到步进电机的A相线圈
- **B+, B-**: 连接到步进电机的B相线圈

> 注意：步进电机驱动器需要独立的电源供电，电压应根据步进电机规格选择，通常为12V或24V。

### 2. 舵机连接

- **红线(电源线)**: 连接到5V电源
- **棕线/黑线(地线)**: 连接到GND
- **橙线/黄线(信号线)**: 连接到ESP32的GPIO23

### 3. 超声波传感器(HC-SR04)连接

- **VCC**: 连接到5V电源
- **TRIG**: 连接到ESP32的GPIO25
- **ECHO**: 连接到ESP32的GPIO33（注意：一些ESP32需要使用分压电路将ECHO信号从5V降至3.3V）
- **GND**: 连接到地线

#### ECHO引脚连接注意事项
由于超声波传感器的ECHO输出为5V，而ESP32的输入引脚只能接受3.3V，需要使用分压电路：

```
ECHO引脚 ---- 1KΩ电阻 ---- ESP32 GPIO33
                |
             2KΩ电阻
                |
               GND
```

### 4. 循迹传感器模组连接

每个循迹传感器模块有三个引脚：VCC、GND和OUT(信号输出)

- **VCC**: 所有传感器VCC连接到3.3V或5V（根据传感器要求）
- **GND**: 所有传感器GND连接到地线
- **OUT-1**: 传感器1的信号线连接到ESP32的GPIO13
- **OUT-2**: 传感器2的信号线连接到ESP32的GPIO12
- **OUT-3**: 传感器3的信号线连接到ESP32的GPIO14
- **OUT-4**: 传感器4的信号线连接到ESP32的GPIO27
- **OUT-5**: 传感器5的信号线连接到ESP32的GPIO26

### 5. 电源电压检测电路

使用分压电路将电池电压降低到ESP32 ADC可接受的范围：

```
电池正极 ---- 10KΩ电阻 ---- ESP32 GPIO7(ADC)
                |
              1KΩ电阻
                |
               GND
```

这个分压比例为11:1，适用于监测11V左右的电池电压。

### 6. 继电器模块连接

项目使用两个继电器来控制额外的设备，例如电磁铁、电动机或其他执行器：

#### 继电器1连接
- **VCC**: 连接到5V电源
- **GND**: 连接到地线
- **IN1**: 连接到ESP32的GPIO19
- **COM**: 连接到所控制设备的电源正极
- **NO(常开端)**: 连接到所控制设备的输入端
- **NC(常闭端)**: 通常不使用，除非需要反向逻辑

#### 继电器2连接
- **VCC**: 连接到5V电源
- **GND**: 连接到地线
- **IN2**: 连接到ESP32的GPIO21
- **COM**: 连接到所控制设备的电源正极
- **NO(常开端)**: 连接到所控制设备的输入端
- **NC(常闭端)**: 通常不使用，除非需要反向逻辑

> 注意：继电器模块通常是低电平触发，即当ESP32输出LOW时继电器被激活。如果您的继电器模块是高电平触发，需要在代码中调整RELAY_ON和RELAY_OFF的定义。

## 电源管理

- ESP32及低功耗组件可以通过USB或3.3V稳压器供电
- 步进电机需要独立的12V-24V电源供电
- 确保所有组件共地，即所有模块的地线都连接到同一地线

## 接线注意事项

1. **电平转换**：ESP32是3.3V逻辑电平，而一些传感器可能使用5V逻辑电平，需要使用电平转换电路。

2. **电源隔离**：步进电机会产生电磁干扰，建议为步进电机使用独立的电源，并添加去耦电容。

3. **线材选择**：
   - 电源线使用足够粗的导线以减少电压降
   - 信号线尽量短，减少干扰
   - 对于长距离布线，考虑使用屏蔽线

4. **防反接保护**：考虑添加二极管防止电源反接造成的损坏

5. **热插拔保护**：避免在通电状态下插拔连接器，尤其是步进电机

6. **继电器保护**：当继电器控制感性负载（如电机、电磁铁）时，在负载两端并联续流二极管，防止反电动势损坏电路。

## 接线图示例

步进电机驱动器接线示意：

```
ESP32 ---- 限流电阻 ---- D36A驱动器 ---- 步进电机
电源 -------------------------------
```

超声波传感器接线示意：

```
ESP32 GPIO25 ----------------- HC-SR04 TRIG
ESP32 GPIO33 ---- 分压电路 ---- HC-SR04 ECHO
ESP32 5V -------------------- HC-SR04 VCC
ESP32 GND ------------------- HC-SR04 GND
```

继电器模块接线示意：

```
ESP32 GPIO19 ----------------- 继电器1 IN
ESP32 GPIO21 ----------------- 继电器2 IN
ESP32 5V --------------------- 继电器 VCC
ESP32 GND -------------------- 继电器 GND
电源正极 --------------------- 继电器 COM
负载设备 --------------------- 继电器 NO
```
