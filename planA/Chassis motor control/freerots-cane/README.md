# ESP32智能拐杖项目

这是一个基于ESP32和FreeRTOS的智能拐杖项目，利用超声波传感器、步进电机、舵机和循迹传感器实现智能导航和路径识别功能。

## 项目概述

该智能拐杖系统可以通过超声波传感器检测障碍物，使用循迹传感器进行路径导航，并通过步进电机和舵机机构实现物体的抓取和放置功能。系统使用FreeRTOS实现多任务并行处理，提高了系统的响应性和可靠性。

## 硬件需求

- ESP32开发板
- 超声波传感器(HC-SR04)
- 步进电机 x2 (使用D36A步进电机驱动)
- 舵机 x1
- 循迹传感器模组 (5个光电传感器)
- 继电器模块 x2
- 电池电源
- 电源电压检测电路
- 机械结构件

## 接线说明

### 步进电机接线

#### 步进电机1
- STEP引脚 -> ESP32 GPIO18
- DIR引脚 -> ESP32 GPIO8
- SLEEP引脚 -> ESP32 GPIO3

#### 步进电机2
- STEP引脚 -> ESP32 GPIO15
- DIR引脚 -> ESP32 GPIO16
- SLEEP引脚 -> ESP32 GPIO17

### 舵机接线
- 信号线 -> ESP32 GPIO23
- 电源线 -> 5V
- 地线 -> GND

### 超声波传感器接线
- TRIG引脚 -> ESP32 GPIO25
- ECHO引脚 -> ESP32 GPIO33
- 电源线 -> 5V
- 地线 -> GND

### 循迹传感器接线
- 传感器1 -> ESP32 GPIO13 (模拟输入)
- 传感器2 -> ESP32 GPIO12 (模拟输入)
- 传感器3 -> ESP32 GPIO14 (模拟输入)
- 传感器4 -> ESP32 GPIO27 (模拟输入)
- 传感器5 -> ESP32 GPIO26 (模拟输入)
- 电源线 -> 5V
- 地线 -> GND

### 电源电压检测
- 电压检测引脚 -> ESP32 GPIO7 (ADC输入)

### 继电器接线
- 继电器1控制引脚 -> ESP32 GPIO19
- 继电器2控制引脚 -> ESP32 GPIO21

## 功能说明

1. **障碍物检测**：通过超声波传感器检测前方障碍物距离，当距离小于9cm时触发相应动作。

2. **路径导航**：使用5个循迹传感器进行路径识别和导航：
   - 当左侧传感器检测到黑线时，控制系统向右转
   - 当中间传感器检测到黑线时，控制系统直行
   - 当右侧传感器检测到黑线时，控制系统向左转
   - 当所有传感器都检测到黑线或者都没检测到黑线时，控制系统停止

3. **物体抓取**：使用步进电机和舵机协同工作，可以实现物体的抓取、提升和放置功能。

4. **电器控制**：使用继电器模块控制外部设备（如电磁铁、电动机等），可用于抓取机构的辅助控制或其他执行器的开关控制。

5. **多任务处理**：使用FreeRTOS实现多个任务并行执行：
   - 超声波测距任务
   - 循迹导航任务
   - 步进电机控制任务
   - 舵机控制任务
   - 继电器控制任务
   - 电源电压监测任务

## 使用说明

1. 使用PlatformIO或Arduino IDE编译上传代码到ESP32开发板
2. 按照接线图连接各个模块
3. 上电后系统将自动运行：
   - 当无障碍物时，系统进入循迹导航模式
   - 当检测到障碍物时，触发物体抓取动作序列
   - 系统会根据预设任务序列自动执行不同的任务

## 注意事项

1. 确保电池电压充足，系统会定期检测电池电压并通过串口输出
2. 步进电机需要足够的电流供应，建议使用独立的电源为步进电机供电
3. 调整超声波传感器和循迹传感器的阈值以适应不同的环境条件
4. 在使用过程中，避免长时间连续运行步进电机，以防过热
